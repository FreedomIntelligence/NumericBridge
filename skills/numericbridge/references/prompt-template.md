# NumericBridge request template / 通用任务模板

Describe what you want to test or deliver. Leave unknown details blank. The
agent follows [request confirmation](request.md) and designs the test.

## 中文

```text
请用 NumericBridge 帮我【测什么，或想解决什么问题】。
已有材料（可选）：【案例目录、交接记录或链接】。
限制（可选）：【可用环境、预算或不能改动的内容】。
标准 A/B 任务按原工作负载和固定验收标准执行，通过后才结案。独立测量或诊断任务请明确写出范围。
社区分享（可选）：如需审核，可请求生成脱敏预览；发送前单独确认对应稿件。不填写则只交付本地结果。

按工作流执行到交付。跨轮时保存检查点和下一步；如果无法继续，说明卡在哪里、何时能恢复。
```

## English

```text
Use NumericBridge to [test something or solve a problem].
Existing material (optional): [case directory, handoff, or link].
Constraints (optional): [allowed environment, budget, or work to leave untouched].
Standard A/B tasks stay open until the original workload meets the fixed acceptance criterion. State the scope explicitly for standalone measurement or diagnosis tasks.
Community sharing (optional): Request a redacted preview for review if desired; sending the exact draft needs separate approval. Otherwise deliver locally.

Follow the workflow through delivery. Save the checkpoint and next action between turns. If blocked, state why and what would let work resume.
```
